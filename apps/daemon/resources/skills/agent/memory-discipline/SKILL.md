# memory-discipline 技能（长期记忆检索纪律）

## 核心纪律

**能力在场才检索，能力缺席不硬查。** 本技能出现在清单里 = memory_search 工具已注册可用；本技能从清单消失 = 记忆未启用或未配置（端点/存储缺席），此时跳过全部记忆检索动作，不调用任何记忆工具，按任务指令与知识图谱约束继续。

## 何时查（三点召回链）

与开工四查、决策点双查、收口召回点对称——开工查「怎么干」、决策查「怎么定」、收口查「怎么收」：

1. **开工时**：接到任务后、动手前，按任务意图/类型描述做一次 query（如「用户对本类任务的偏好」「XX 类工作的处理习惯」）。
2. **决策点**：任务中途遇到未规划到的点、需要自主决策时，按该决策点的意图检索用户使用习惯与既往同类问题的处理方案。
3. **收口时**：任务收口/向用户交代前，按「收尾/善后/清理」意图检索一次用户习惯偏好（临时文件处置、现场恢复、文档落盘位置、交代方式等）。

## 怎么查（query 提炼方法）

- **用意图，不用原文**：query 是你对任务的理解与提炼，不是用户原话的转写（语音转写常生硬、有错别字——先做一次问题重写再查）。
- **query 形态**：任务意图/类型描述（开工时）或决策点意图（决策时），如「用户对本类任务的偏好」「收尾善后的习惯做法」。
- **domain 可选**：不传 = 全域；habit = 用户怎么干活（换个团队也成立）；general = 环境与通用工作方式；project = 绑定具体项目的事实。

## 命中后怎么用

- 命中即遵守——但与当前任务指令冲突时以任务指令为准，涉及代码/项目现实以知识图谱为准。
- 有既往习惯时，将「之前的处理习惯」与「当前代码事实」综合考量后再定方案——不能只看代码不看用户习惯，也不能拿旧习惯硬套已变的事实。
- 记忆结果中的「[进展]…（sid: xxx）」行可直接作 read_session 的 sessionId。

## 降级语义

- 工具返回「长期记忆未启用或未配置」→ 正常继续，不参考长期记忆，不重试。
- 工具返回「记忆检索降级」→ 按任务指令继续，本次不参考长期记忆。
- 零命中 → 正常继续（topK 是上限不是配额）。

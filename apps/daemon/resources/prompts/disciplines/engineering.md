# 工程纪律（全局——所有 agent 遵守）

①并行开发一律隔离 worktree：并行执行多个开发工作时，各自在隔离 worktree 的分支上干活与提交，禁止共享同一工作树并行写；图谱产出型任务（kg-bootstrap/kg-review）不开 worktree，主工作树执行（kg 库是 SQLite 单写面，隔离副本各自写库合并必分叉）。任何执行者都不自行 merge——各分支的合入由 MainAgent 在计划阶段检查点统一执行（merge 冲突由 MainAgent 裁决解决）。

②计划阶段检查 commit：推进/验收计划阶段时核查工作树提交情况，有未提交工作即要求先提交再推进；收尾前先提交——未提交的工作等于没做。

③过程临时文档不落项目仓：任务 brief / evidence / 设计候选 / 验证记录等过程性临时文档一律产出到 workspace 根（会话 cwd）的 `docs/` 下（如 `<workspace>/docs/temp/`），禁止写进项目仓的 `docs/`（项目仓 docs 只留长期工程文档——ADR/设计系统/协议文档等）；代码事实与架构知识一律进知识图谱（按各角色落账通道即时入账），不在文档里另记一套——文档与图谱双轨是已判过的反模式（v1 kg 体系即因此而退役）。

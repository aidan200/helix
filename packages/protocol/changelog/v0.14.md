### 17.19 快照体量批（管家重连循环 bug 第二轮）微批备案

> 版本位不动（additive 微批，追加当前版本文件尾部——§40 分配规则）。

- **1 字段**：`InstanceChannelHistory.truncated?: boolean`（agent.ts additive）
  ——daemon 快照组装对 per-instance channel 不再全量下发（F-14⑤「完整
  保留不截断」经背压断连循环事故降级）：每通道保最新 channelTail 条且
  主轴尾窗 + 全部通道合计受 SNAPSHOT_BUDGET_BYTES（2MB）序列化字节预算
  约束；被裁时 `truncated: true`，缺省 = 未截断（小会话零变化）。主轴
  超预算时 tail 同步收窄（tailStartCursor 指向实际首条，loadHistory
  「加载更早」续拉语义不变；分页页体同预算）。
- 事故链（2026-09-20 实测）：大会话（3754 entries + 40 实例 + 4972
  tool_calls 结果共 8.5MB）单帧快照 15.51MB；welcome attach 快照 +
  reconnect replay subscribe ack 快照 = 每连接 31MB，慢客户端（webview
  解析 15.5MB JSON 阻塞主线程）排水不及 → daemon 发送缓冲 > 8MB →
  close(4000) → 800ms 退避 + 主线程阻塞 ≈ 2.0s 恒定周期自持循环。
- 行为语义（daemon 侧，零协议命令/事件变更）：快照/分页帧体有界化；
  close 发起方日志区分（daemon: 背压/握手拒绝/握手超时/坏帧 | client）
  + 发送缓冲半限水位线预警（连接级一行式日志扩展）。
- 兼容性：additive——旧 shell 忽略 truncated 键照常渲染通道最新条目；
  旧 daemon 缺省不携带（读侧按未截断处理）。
- 零命令/事件计数变更（命令 92/事件 111 不动）。

## §17.27.3 channels 惰性化批（SubAgent 通道历史按需拉取，additive 微批）

  channels（三槽分组）+ hasMore + nextCursor。
